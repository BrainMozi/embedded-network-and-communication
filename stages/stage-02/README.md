# 阶段二：车载网络与协议

本阶段按第二讲课件完成一个基于 CAN 的分布式汽车灯光控制系统。Ubuntu 中由 Python 控制端和独立灯光 ECU 进程通过 SocketCAN `vcan0` 通信；`0x256` 传控制命令，`0x257` 回报目标/实际灯态与同序号结果。

## 本阶段实现

- 六类软件灯态、八种控制命令；左右转向互斥，双闪同时控制两侧。
- 五项 ECU 任务：CAN 接收、命令解析、灯光控制、20 ms 状态反馈、100 ms 系统监控。
- VS Code 面板实时显示灯态、CAN 帧、任务状态和命令到反馈的事件链；可注入虚拟灯路故障并测试非法命令。
- 已保存 `candump` 抓包与结构化事件日志，报告列出实测数据和限制。

## 运行

在 Ubuntu 的 VS Code 打开 `can_lighting_demo/`，选择项目 `.venv/bin/python`，按 **Ctrl+Shift+B** 运行默认任务“启动 CAN 灯光演示（Python）”。该任务会先创建 `vcan0`，再启动 ECU 和面板；无需手工输入终端命令。

## 范围说明

本阶段实际验证的是 Linux `vcan0` 上的 CAN 软件报文和 Python 用户态任务，不连接实体 CAN 适配器或真实灯具，也不宣称硬实时。LIN、车载以太网/TSN 与 AUTOSAR 为课程学习内容，不属于本阶段已实现的项目功能。
